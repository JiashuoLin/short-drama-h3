# H3 分段共同契约

本文件是新套件共享的结构与 owner 规则。只用于明确选择 `workflow_suite: short-drama-h3`、
`storyboard_unit: video_segment` 的项目；不凭标题自动迁移旧项目。已有项目选择冲突时报告具体字段。

## 唯一生产单位

`SEG-...` 是计划生成单位，一个 SEG 对应一个 `MOTION-...` 和一次逻辑视频生成请求；因此一个 SEG 最多一份段首冻结关键帧提示词，不能按其中的 SHOT 分别建立图片提示词。
一个 SEG 可以包含多个 `SHOT-...`；SHOT 是段内切镜和内容定位符，不拥有独立 MOTION、参考图或视频 job。
同一 SEG 可以有多次有记录的生成尝试。实际文件的版本与剪辑入出点不改变创作 ID 的含义。

## 分镜格式

`分镜.md` 用 `## SEG-... · 中文名`，SEG 固定六个必填字段，并可追加一个 `参考图占位` 字段：

| 字段 | 契约 |
| --- | --- |
| 来源 | 一个现有剧本场景 ID；一段不跨场次、时间跳跃或地点变化 |
| 时长 | 计划秒数；不超过 15 秒，受已接受原生时长区间约束 |
| 全局时间 | `00:00.000–00:12.000`；差值等于段时长 |
| 段首状态 | 开始生成时已经成立的可见状态 |
| 段尾交接 | 本段结束时的可见状态、声音落点与必要接续关系 |
| 环境声音 | 剧本已有环境、动作声音与静默边界 |
| 参考图占位（可选） | 本段需要下游核对的身份、造型、地理、道具、段首或结束画面类别；只能写需求和缺口，不能写真实 `REF/PLAN` 路径 |

每段下用 `### SHOT-...`，恰好五字段：`时间`、`景别`、`运镜`、`画面动作`、`台词`。
时间是段内局部区间，例如 `0.00–5.00s`。所有 SHOT 从 0 开始、连续递增、无空洞或重叠，末尾等于 SEG 时长。
通常一段 1–3 镜、8–13 秒，这是创作建议而非数量门禁。每次切镜必须带来信息、关系、情绪、空间或注意变化。
SHOT ID 在本集唯一，稳定性优先于编号外观；移动后不强制将 ID 改成新父段前缀。

SEG/SHOT 不添加 `目的`、`图片提示词项`、`视觉依据`、`输入参考图`、真实 `REF/PLAN` 绑定或视频正文。SEG 可以添加 `参考图占位`，用于保留原有业务中的“待补参考图”标志；它不是实际参考图清单。每个 SEG 必须添加 `### 空间规格`；需要冻结图时再按固定顺序添加 `### 段首冻结关键帧提示词`、`参考图说明：` 和独立的 `### 负面提示词`。空间规格保留表格化的机位、结构、前中后景、画外与参考图字段；它不是图片提示词。
SHOT 不添加独立 `起点`、`终点`、`唯一动作`、冻结帧；需要的状态因果写进画面动作。
段首冻结正文使用 `### 段首冻结关键帧提示词`，是视频段首图片提示词的唯一默认入口；段尾冻结正文只有用户明确要求段尾交接图时才使用 `### 段尾关键帧提示词`。中间 SHOT 不写图片提示词或关键帧。
这些 H3 标题是 SEG 的直接子节，即使排在最后一镜之后也不属于那一镜。首帧只投影段首，尾帧只投影段尾。

## 视频格式

`视频提示词.md` 顶部使用 `## Part 1 · 主题定义`，含 `preprompt_rules:`、
`style_and_tone_lock:`、`story_continuity:`、`subject_definitions:`、`ref_mapping:`。
后续每个 `## MOTION-... · 中文名` 必填：

`分镜段`、`时长`、`生成方式`、`输入参考图`、`起始帧`、`段首状态`、`段尾交接`、`成员分镜`、`准备状态`。

`分镜段` 指向唯一现有 SEG；时长、状态和成员 SHOT 的顺序及局部区间原样继承分镜。
`成员分镜` 示例：`SHOT-EP001-001-01（0.00–5.00s）；SHOT-EP001-001-02（5.00–12.00s）`。
`生成方式` 只写 `图生视频` 或 `文生视频`，表达创作意图，不指定工作流节点。
文生必须有创作者明确选择，补非空 `静态视觉锚点`，并把其可见事实写入正文。
无独立首帧实图时写 `起始帧：无独立实图；开场按 SEG-... 的段首状态实现`，这不阻断仅人物图的参考生成。

`### 可复制提示词` 下直接写一条纯 Markdown 正文，不加 `>` 引用符，也不套 `text` 代码块；复制内容按以下精确顺序包含六个字段：

1. `subject_definitions:`
2. `summary:`
3. `retention_analysis:`
4. `detailed_description:`
5. `overall_soundscape:`
6. `non_diegetic_music:`

六段正文写中文；固定字段、`[Shot N]`、`At MM:SS.mmm`、`<Subject N>`、`<Picture N>`、
`<Video N>`、`<Audio N>`、`(Sx)`、`<d>[chinese] ...</d>` 和 retention 标记保留英文。
`[Shot 1]` 从局部 0 开始不加切点；其后如 `[Shot 2] At 00:05.000`，严格使用分镜局部切点。
正文每镜包含已定景别与运镜，结尾明确落到本段时长和段尾状态。
禁止第二套段内分镜、独立 SHOT 提交正文或创作容器账本。

## 参考身份与局部编号

参考选择只写在 MOTION；视频提示词 owner 读取实际媒体内容及视觉设定后绑定，不回填分镜。
图片提示词 `IMG-...` 只表示提示词条目；没有《图片提示词.md》也能绑定用户真实照片。
段首图可选：需要制作时读取 SEG 冻结正文，经 image-prompts 与图片生产后再绑定真实文件。

```text
REF-PERSON（顺序：1）· 输入/参考图/人物.png《人物照片》（用途：身份；控制：脸型、发型；不得控制：构图、动作、表情）
PLAN-PERSON（顺序：1）《人物照片》（用途：身份；控制：脸型、发型；不得控制：构图、动作、表情）
```

REF 路径是项目相对路径，只用 `/`。多项用 `；` 分隔。每个 MOTION 的顺序从 1 连续编号，
该顺序仅表示 producer 的外部输入索引；同一文件在本段只列一次，多个控制事项合并到同槽。
人物、造型、地点和道具的属性参考映射到稳定 `<Subject N>`，其来源图片在定义中以 `<Picture N>` 引用，不占独立 Picture 条目；经确认的首帧、尾帧或构图锚点图按官方规则独立定义 `<Picture N>`，编号与输入参考顺序一致。
用途取 `身份`、`造型状态`、`地理`、`构图`、`尺度`、`效果`、`起始帧`、`结束帧`、`风格` 之一。
图片只有角色身份用途时，不能顺带决定场景、构图或表情。真实首尾约束如实交接，由外部技能判断可执行方式。
一段内素材控制范围须持续有效；需要中途更换绑定链时回 storyboard 拆 SEG。

全局 `ref_mapping:` 按一行一个映射汇总，避免把局部图片编号当成全片图片身份：

```text
MOTION-EP001-001 + REF-PERSON + <Subject 1> + 1
MOTION-EP001-002 + REF-PERSON + <Subject 1> + 2
```

PLAN 同样映射但不写虚构路径。全片 `<Subject N>` 和说话人 `(Sx)` 各自稳定，二者不要求数字相同。S 编号按整集目标视频中实际发声事件的首次出现顺序建立；voice design 只提供声音事实，不决定编号。旧项目已有且符合该顺序的已接受映射时原样继承。
同一 REF 可映射多个 Subject，按 `<Subject 1>, <Subject 5>` 写在同一项中。本段未出现的主体不必写入本段正文；出现时完整重述定义，Subject 编号不得因本段 REF 顺序改变。
当前交接只支持一组前段续接媒体和一个可选音频输入，字段值各为一条项目相对路径：

| 可选字段 | 支持范围 |
| --- | --- |
| 续接视频 | 上一段实际视频；对应 `<Video 1>`，完整交接时必须与实际尾帧成对 |
| 实际尾帧 | 由上述视频取得的实际图片；以独立尾帧职责交接，不自动占 Picture 编号 |
| 输入音频 | 用户已提供并指定的单个实际音频；对应 `<Audio 1>` |

无素材时省略字段或写 `无` / `N/A`。图片、视频、音频路径不能写成分号清单，不接收多个视频或多个音频。
待续接草稿可先登记已经取得的一项，另一项保留缺口；结构检查允许该中间状态，完整性与交接检查仍要求两项齐备。
尾帧需要在正文用 Picture 引用时，再将同一实际图片登记为唯一 REF；Picture 编号仍只来自输入参考图顺序，
实际尾帧字段保留来源职责，不再登记第二份图片 REF。视频有音轨不自动构成 Audio 输入；需要 Audio 标签时先落实实际音频文件。
当前不支持通用视频清单、音频清单或 `<Video 2>` / `<Audio 2>`；不能写看似可用而交接会忽略的字段。
超出上述单槽范围时记待调整并报告限制，不静默丢素材，也不新建第二执行器。

## 创作准备状态

| 精确值 | 行为 |
| --- | --- |
| 草稿 | 内容或真实创作选择尚未闭合；不交接生成 |
| 待参考 | 列出必要图片缺口，保留真实 REF；该段不写最终可复制提示词，其他完成段保留 |
| 外部挂图计划 | 用户明确计划在项目外挂图；允许完整文稿与 PLAN，落实真实素材并转换 REF 前不可交接 |
| 待续接 | 已接受实际结果续接路由，缺上一段实际视频或实际尾帧；保留草案，不改独立生成 |
| 可交接 | 创作正文与必要真实素材齐备；不等于外部预检通过、生产授权或生成成功 |
| 待调整 | 外部反馈或审查指出创作输入问题；记录具体问题并回对应 owner |

状态后可加中文括号或分号说明具体缺口。只写缺口，不在这里记录排队、运行、重试等执行状态。
没有图片不是文生授权；没有独立首帧也不是必然缺图。必要性根据整段一致性需求判断。
只有项目已经接受“实际视频 + 实际尾帧”续接时才启用该依赖；计划段尾、冻结正文和真实结果分开。
实际尾帧偏离已接受段首时，先处理结果或由 storyboard 修订，不能在 MOTION 偷改事实。

## 唯一 owner 与执行边界

| 事实或操作 | owner |
| --- | --- |
| 剧情、台词原文、VO/OS、可见文字 | short-drama-h3-write |
| 人物身份、造型、地点、道具、连续性锁 | short-drama-h3-assets |
| SEG/SHOT、空间规格、全部计划时长和切点、段首冻结提示词 | short-drama-h3-storyboard |
| 图片提示词与制作图片用的参考 | short-drama-h3-image-prompts |
| MOTION、六段式、视频参考绑定、准备状态 | short-drama-h3-video-prompts |
| 图片等非视频生产；视频交接与返回来源归属 | short-drama-h3-produce |
| 视频工作流、上传、预检、提交、等待、恢复、输出选择 | 外部 minimax-h3-comfyui-video |
| 实测媒体时间、CUT 入出点与剪辑 | short-drama-h3-edit |

新套件不提供视频 adapter、第二执行器或执行队列。本地检查不访问 ComfyUI，不计算帧量化，不修工作流。
计划时间和实际媒体时长分开：外部返回不可执行的时长限制时回 storyboard，实际偏差由 edit 测量。
只提供文件和命令行工作流，无 Dashboard、前端或浏览器启动。
独立配音/TTS、时间线音乐的完整迁移以及整集目标时长/未拍覆盖校验明确暂缓；不能将局部结构通过宣称为这些能力已完成。
